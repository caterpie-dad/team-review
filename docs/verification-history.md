## 검증의 한계

실제 Confluence/GitHub 계정과 LLM API 자격 증명이 제공되지 않아 **외부 실서비스 연결 및 실제 모델의 평가 정확도는 검증하지 않았다.** 모의 LLM은 사전 정의된 합성 코드 유형에 따라 결정적 JSON을 반환하는 테스트 대역이다. 모의 응답의 악성 지시 무시는 실제 모델의 프롬프트 주입 저항성을 입증하지 않는다. 실제 모델에서는 도구 접근 차단, 대상 개인의 근거 허용 목록, 인용 검증 및 평가자 검토가 적용되지만 의미적 판단의 완전한 정확성을 보장하지 않는다.

운영 도입 시 사용하려는 Confluence 배포판의 버전 조회 권한, GitHub 저장소 접근 권한, LLM의 JSON 출력 지원을 실제 환경에서 확인해야 한다. 대규모 조직 부하와 다중 노드 운영은 검증 대상이 아니다. 이 배포는 SQLite 기반 단일 프로세스이며 평가 실행도 한 번에 한 건이다.

최초 확인 시 배포된 API의 팀원 10명은 계정 목록이 정상인 상태였고, 새 브라우저 접속에서 팀원 관리 화면이 열렸다. 따라서 사용자 탭의 정확한 실패 원인은 확정하지 못했다. 구버전 화면과 새 API의 조합 및 선택 필드 누락에 대비하여 서버에서 누락/null 계정 목록을 빈 배열로 반환하고, 화면 목록과 편집 창에도 배열 확인을 추가했다. 기존 저장 데이터와 평가 스냅샷은 다시 쓰지 않는다. 화면 파일은 내용 해시로 버전을 지정하고 HTML은 no-store, 정적 파일은 no-cache로 갱신한다.

관련 API·연차·호환성 테스트 **35개 통과**(53.48초), Ruff 및 JavaScript 구문 검사 통과. `scripts/browser_members_check.py`에서 실제 누락/null 레코드와 누락된 API 응답을 재현하여 팀원 탭 열기 → 편집 → 계정 추가 → 저장 → 재열기까지 확인했다. 기존 ID 관리, 신규 팀원 등록, 연차별 평가, 모바일 검증도 통과했고 JavaScript 오류는 없었다. [브라우저 검증 기록](../artifacts/level-verification.json).

Docker 재배포 후 실제 대시보드에서 기존 팀원 10명 표시, 기존 계정이 포함된 편집 창 열기, 새로고침 후 팀원 탭 재진입을 확인했다. 사용자 데이터를 수정하지 않았으며 JavaScript 오류는 없었다. [배포 브라우저 검증 기록](../artifacts/deployed-members-verification.json).

## 적응형 분석과 판정 캐시 검증 — 2026-09-27

전체 자동 테스트 **115개 통과**(155.06초) 후 파일 수 상한과 선택적 snapshot API 실패 사례를 추가하여 분석 전용 테스트 **22개 통과**(11.82초)를 확인했다. Ruff 및 JavaScript 구문 검사를 통과했다. 작성자 전환·공동 저자·병합·부모 연결 단절·파일 hash 오류·잘못된 hunk·rename·파일 크기/수 한도·네트워크 실패에서 원래 diff가 유지된다. 삭제된 중간 테스트 보존, 다른 작성자의 기존 코드가 순변경에 포함되지 않음, 원본 누락 시 통합 근거 선택 거부, 취소 전파도 확인했다.

캐시는 근거·rubric·귀속 범위·모델·인증 변경 시 무효화되며, 잘못된 저장 판정은 재검증에서 거부된다. 복제 평가의 동일 근거는 LLM 재호출 없이 처리하고 강제 재분석은 다시 호출한다. API가 보고한 토큰 값과 실제 전송 문자 수를 구분하여 저장한다.

`scripts/benchmark_analysis.py`는 별도 HTTP 모의 서비스를 띄워 두 작성자가 같은 파일을 연속 수정하는 48개 커밋을 비교한다. 기본 3줄 문맥 diff, 이미 존재한 코드, 중간에 추가 후 제거된 테스트를 포함한다. 첫 실험의 전체 파일 문맥 사례는 최종 보고에서 제외하고 3줄 문맥 사례로 다시 측정했다.

| 작성자 수 | 원본 근거 본문 | 통합 근거 본문 | LLM 호출 원본→통합 | 동일 근거 재실행 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 151,351자 | 20,807자 | 5→1회 | 0회 |
| 2 | 151,351자 | 20,807자 | 6→2회 | 0회 |

원본 48개를 모두 보존하고 통합 근거 2개를 추가했다. 본문 문자 수 감소는 **86.3%**이며 토큰 감소율로 해석하지 않는다. 모의 서비스 지연 시간은 실제 모델 추론 시간을 나타내지 않는다. 모의 판정기는 코드 키워드에 반응하는 테스트 대역이므로 원본/통합 점수의 일치나 실제 판정 정확도를 검증하는 용도로 사용하지 않았다. [벤치마크 기록](../artifacts/analysis-benchmark.json).

`scripts/browser_analysis_check.py`에서 평가 실행 → 분석 효율 표시 → 통합 근거 → 원본 커밋 근거 → 평가 복제 → 캐시 사용 표시 → 모바일 레이아웃을 검증했다. JavaScript 오류 없음. [브라우저 검증 기록](../artifacts/analysis-browser-verification.json), `artifacts/analysis-efficiency.png`, `consolidated-evidence.png`, `analysis-efficiency-mobile.png`에 화면을 보존했다.
